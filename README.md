# anyserver

**anyserver** helps you repurpose old laptops and computers into general-purpose Linux servers with minimal effort.  
The goal is to provide a straightforward setup process for creating a home or small-scale server environment without unnecessary complexity.

---

## 🖥️ Recommended Operating System

For the best experience, we recommend using **Ubuntu Server**, as it is widely supported and has a large community for troubleshooting.

- **Download Ubuntu Server**: [Ubuntu Server Download](https://ubuntu.com/download/server)
- **Installation Tip:** During setup, select the **full installation** to ensure maximum package support and compatibility with Docker.

---

## 🐳 Application Deployment with Docker

To deploy applications quickly and efficiently, we utilize **Docker**.

- **Docker Installation Guide**: [Install Docker on Ubuntu 22.04](https://www.digitalocean.com/community/tutorials/how-to-install-and-use-docker-on-ubuntu-22-04)
- **Note:** If you encounter issues during installation or configuration, please [open an issue](../../issues) in this repository so we can assist.

---

## 💡 Why anyserver?

- Extend the life of old hardware  
- Easily set up a personal server for apps, media, or backups  
- Simple, Docker-based application deployment
